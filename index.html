🐞 Cómo funciona un depurador de Java

Un depurador (debugger) detiene tu programa mientras funciona para que veas qué pasa por dentro. Aquí puedes probarlo con un programa pequeño.

1️⃣ ¿Para qué sirve?

Para buscar errores (bugs). En vez de adivinar, paras el programa y miras el valor de cada variable, línea a línea.

2️⃣ ¿Cómo lo hace?

Tu programa corre dentro de la JVM. El IDE (IntelliJ, Eclipse, VS Code…) se conecta a ella y le manda órdenes: «para aquí», «da un paso», «dime cuánto vale total».

3️⃣ ¿Qué vas a ver?

Un breakpoint (punto rojo donde parar), el paso a paso, las variables y la pila de llamadas.
